A standalone GitHub-compatible git forge in a single Node process, standard library only: git smart HTTP (upload-pack protocol v2, receive-pack v0) with its own object store and packfile implementation, the REST v3 API for repositories, contents, issues and pull requests, the GraphQL v4 API with introspection, and an MCP endpoint — all over one shared in-memory store, fully deterministic.

## Run it

```sh
node --experimental-strip-types main.ts
```
